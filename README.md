## 一、AI 产品项目：校园二手信息聚合搜索工具

一个面向校园二手交易群的消息聚合、AI 分类与搜索工具。把分散在多个 QQ 群、淹没在闲聊中的二手交易信息，自动采集、结构化、并提供关键词搜索 + 订阅提醒。

> **声明**：本仓库仅用于个人能力展示与学习交流。出于隐私保护，已移除所有原始群聊截图、聊天记录及真实群号，请勿直接用于任何可能侵犯他人隐私的场景。

### 项目定位
- **问题**：校园二手交易信息分散在多个 QQ 群，90% 消息是闲聊，同学想买东西需要逐群翻阅。
- **方案**：轻量化的信息采集 + AI 结构化 + Web 搜索 + 订阅推送。
- **形态**：
  - 消息采集端（`push_notify`，Python + NapCat）
  - 信息聚合与搜索后端（`trade_hub`）
  - 移动端 PWA（`tradepulse-group-assistant`）

### 核心数据（作品展示用，已脱敏）
- 覆盖 7 个校园二手群，采集约 2557 条消息
- AI 结构化 1475 条，提取有效交易信息 488 条
- 表情包 / 无效信息过滤率约 18%
- 支持关键词搜索 + 订阅提醒，PWA 零安装
