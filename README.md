# AI 驱动的校园二手信息聚合搜索工具

一个面向校园二手交易群的消息聚合、AI 分类与搜索工具。把分散在多个 QQ 群、淹没在闲聊中的二手交易信息，自动采集、结构化、并提供关键词搜索 + 订阅提醒。

> **声明**：本仓库仅用于个人能力展示与学习交流。出于隐私保护，已移除所有原始群聊截图、聊天记录及真实群号，请勿直接用于任何可能侵犯他人隐私的场景。

---

## 项目定位

- **问题**：校园二手交易信息分散在多个 QQ 群，90% 消息是闲聊，同学想买东西需要逐群翻阅。
- **方案**：轻量化的信息采集 + AI 结构化 + Web 搜索 + 订阅推送。
- **形态**：
  - 消息采集端（Python + NapCat）
  - 信息聚合与搜索后端（trade_hub）
  - 移动端 PWA（tradepulse-group-assistant，AI 辅助分类与发布）

---

## 效果数据

- 覆盖 7 个校园二手群
- 累计处理消息 **2,557 条**
- 结构化有效信息 **1,475 条**
- 提取有效交易信息 **488 条**
- 图片内容解析 764 张
- 表情包等噪声消息过滤比例约 18%
- OCR 二次确认商品信息 126 条

## 关键设计

- **合规采集**：使用 NapCat 协议端方案，避免侵入式爬虫；群号等敏感信息已脱敏。
- **分级 AI 处理**：先用规则 + 关键词完成冷启动闭环，再引入 AI 对语义复杂或图片内容进行解析。
- **缓存与成本控制**：对重复内容复用解析结果，避免无效的大模型调用。
- **零安装体验**：移动端以 PWA 形式运行，无需应用商店发布。
